# Student Management System

A full-stack Java web application for managing student records with secure admin authentication and complete CRUD operations.

## 🚀 Live Demo

https://studentmanagementproject-r25e.onrender.com/

## 📌 Project Overview

The Student Management System allows an administrator to manage student information through a web-based interface.

The application provides authentication, dashboard statistics, student search, and complete CRUD functionality.

The project is deployed using Docker on Render and uses TiDB Cloud as the production database.

## ✨ Features

- Admin Login and Logout
- Dashboard with student statistics
- Add Student
- View Students
- Search Students
- Edit Student
- Delete Student
- Form validation
- Authentication filter
- MySQL-compatible cloud database
- Responsive web interface
- Docker-based deployment
- Cloud deployment with Render
